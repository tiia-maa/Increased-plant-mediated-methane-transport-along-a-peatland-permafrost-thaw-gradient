# Increased plant mediated methane transport along a peatland permafrost thaw gradient
R code used for data processing and analysis for the Määttä et al (2026) manuscript "Plant belowground traits indicate increased plant-mediated methane transport along a peatland permafrost thaw gradient" (https://doi.org/10.5194/egusphere-2026-467)

## Data cleaning and processing (Maattaetal2026_Stordalen_data_processing.R)
This file contains the R code used to clean and process the datasets (chamber CH4 flux, vegetation survey, root and rhizome trait and meteorological data) used in the manuscript. The code also produces some figures (Fig. B1 and Fig. B10) and tables (Tables 1, C3, C4, and C5) shown in the manuscript.
